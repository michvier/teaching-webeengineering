# Lecture 4 — JavaScript Basics

[`index.html`](index.html) loads the script [`script.js`](script.js) with a `<script src>` tag at the end of the `<body>`, so the page content is already there when the script runs. The script calls `console.log(...)`, which prints a message to the browser console: open the page, press F12 and switch to the *Console* tab to see it.
