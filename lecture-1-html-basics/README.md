# Lecture 1 — HTML Basics

[`index.html`](index.html) is the smallest possible HTML page: the `<!DOCTYPE html>` declaration, an `<html>` element with a `lang` attribute, a `<head>` with the character encoding (`<meta charset>`) and the `<title>` shown in the browser tab, and a `<body>` with a heading (`<h1>`) and a paragraph (`<p>`). Open it in the browser, then compare what you see with the source (right-click → *View Page Source*).
