# Lecture 2 — CSS

[`index.html`](index.html) loads the stylesheet [`style.css`](style.css) with a `<link rel="stylesheet">` tag in the `<head>`. The stylesheet has a single rule: the `body` selector sets `font-family: sans-serif`, and because `font-family` is inherited, the heading and the paragraph change their font too. Remove the `<link>` tag and reload the page to see the difference.
